  PVC (Persistent Volume Claims) 요구사항
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [RWX 필요 - ReadWriteMany] (NFS, CephFS, EFS 등)
  ┌────────────────────────┬───────┬────────────────────────────────────┐
  │ PVC 이름               │ 크기  │ 사용 서비스                        │
  ├────────────────────────┼───────┼────────────────────────────────────┤
  │ vst-data               │ 50Gi  │ sensor-ms, storage-ms, replaystream│
  │ vst-video              │ 200Gi │ sensor-ms, storage-ms, replaystream│
  │ vst-clips              │ 50Gi  │ storage-ms, replaystream           │
  └────────────────────────┴───────┴────────────────────────────────────┘

  [RWO - ReadWriteOnce]
  ┌────────────────────────┬───────┬──────────────────────────┐
  │ PVC 이름               │ 크기  │ 사용 서비스              │
  ├────────────────────────┼───────┼──────────────────────────┤
  │ vst-temp               │ 10Gi  │ storage-ms               │
  │ postgres-data          │ 20Gi  │ postgres                 │
  │ redis-data             │ 10Gi  │ redis                    │
  │ phoenix-data           │ 5Gi   │ phoenix                  │
  │ llm-nim-cache          │ 50Gi  │ LLM NIM (모델 캐시)      │
  │ vlm-nim-cache          │ 50Gi  │ VLM NIM (모델 캐시)      │
  └────────────────────────┴───────┴──────────────────────────┘

  총 스토리지: ~445Gi (비디오 저장량에 따라 증가)
